# Cashbook

一个面向双人/家庭个人使用的隐私优先智能记账项目。

## 项目目标

核心闭环：

1. 两个独立账号加入同一个共享账本。
2. Android 端尽量无感识别微信、支付宝及银行卡消费。
3. 识别结果先进入候选交易层，去重并计算置信度。
4. 高置信度交易自动入账；低置信度交易由用户确认。
5. 共享账本实时同步到两台设备。
6. 后续扩展预算、共同储蓄目标、购买计划和月度总结。

## 隐私原则

本项目以“最小权限、最小采集、本地优先、原文不上传”为默认设计。

- 默认采集优先级：支付通知 > 用户主动截图/OCR > 账单文件导入。
- 短信读取默认关闭，不作为 V0.1 必需能力。
- 全局无障碍默认关闭，仅在通知无法覆盖的特殊场景作为实验性能力。
- 通知原文只在内存中解析，不持久化，不上传服务器。
- 云端只同步结构化交易字段，不同步原始通知、短信或截图。
- 正式构建禁止记录通知原文、短信原文、OCR 原图和认证信息到日志。
- 不接入广告、行为分析或不必要的第三方统计 SDK。
- 所有高敏感权限均需要单独开关，可随时撤销，不影响手工记账。

详细设计见 `docs/PRIVACY_ARCHITECTURE.md`。

## 初始技术路线

- 客户端/共享账本底座：优先评估并二次开发 BeeCount。
- 服务端：优先评估 BeeCount Cloud，自托管。
- Android 自动采集：独立 Capture Adapter Layer，不与账本核心耦合。
- 解析策略：本地确定性规则优先，AI 仅作为可选兜底，默认不发送原始敏感文本到外部模型。

## V0.1

V0.1 只验证一条链路：

```
微信/支付宝支付
  -> 支付通知
  -> 本地识别
  -> 候选交易
  -> 去重/置信度
  -> 共同账本
  -> 另一台设备同步可见
```

短信、无障碍自动读取、后台自动截图不作为 V0.1 前置条件。
